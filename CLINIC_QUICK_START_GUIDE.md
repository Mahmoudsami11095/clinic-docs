# Clinic Quick-Start Reference Cards (Cheat Sheets)
## Smart Clinic Management System (Clinic App)

> **Printing Recommendation:** Print and laminate these two reference cards. Place **Card 1** at the Front-Desk Reception station and **Card 2** at the Doctor's consultation desk.

---

## 📋 CARD 1: Front-Desk Reception & Cashier Cheat Sheet

```
┌────────────────────────────────────────────────────────────────────────┐
│                   5-STEP RECEPTION WORKFLOW CHEAT SHEET                │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  STEP 1: PATIENT ARRIVAL                                               │
│  • Search patient by Mobile Number or Name in top search bar.          │
│  • If New Patient: Click "+ New Patient" (Ctrl + N).                   │
│    Mandatory: Name, Mobile, Age, Gender, and Drug Allergies.           │
│                                                                        │
│  STEP 2: CHECK-IN & WAITING QUEUE                                      │
│  • Locate appointment on "Today's Schedule".                           │
│  • Click the green [ CHECK-IN ] button.                                │
│  • Status turns to "Waiting"; Doctor's screen updates in real-time.    │
│                                                                        │
│  STEP 3: POST-CONSULTATION CHECKOUT                                    │
│  • Patient returns from Doctor's room.                                 │
│  • Click "Billing" -> Select patient (marked "Ready for Checkout").    │
│  • Verify consultation fee + dental procedures + radiology.            │
│                                                                        │
│  STEP 4: COLLECT PAYMENT                                               │
│  • Select payment mode: [ Cash ], [ Card/Visa ], or [ Split ].         │
│  • If Cash: Enter amount received; check change display.               │
│  • If Courtesy Discount: Max 10% (Doctor PIN required if > 10%).       │
│  • Click [ Finalize & Settle Invoice ].                                │
│                                                                        │
│  STEP 5: PRINT RECEIPT                                                 │
│  • Quick Cashier: Click [ Print Thermal Slip (80mm) ].                 │
│  • Corporate / Tax Invoice: Click [ Print A4 Invoice ].                │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│  KEY SHORTCUTS:                                                        │
│  Ctrl + N : New Patient Registration     Ctrl + P : Print Last Receipt │
│  Ctrl + B : Open Today's Bookings        F5       : Refresh Queue      │
└────────────────────────────────────────────────────────────────────────┘
```

---

## 🩺 CARD 2: Doctor & Specialist Chair-Side Cheat Sheet

```
┌────────────────────────────────────────────────────────────────────────┐
│                   DOCTOR CHAIR-SIDE CONSULTATION CARD                  │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  1. QUEUE & SAFETY CHECK                                               │
│  • Click [ Call Next Patient ] from the Waiting Room Queue.            │
│  • CHECK TOP BANNER: Red alert indicates documented Drug Allergies.    │
│  • Review "Medical Timeline" for past visit history & chronic diseases.│
│                                                                        │
│  2. CLINICAL NOTES                                                     │
│  • Enter Chief Complaint (CC) and physical examination findings.       │
│  • Select provisional or final diagnosis.                              │
│                                                                        │
│  3. DENTAL CHARTING (DENTISTS ONLY)                                    │
│  • Open "Dental Chart" tab.                                            │
│  • Toggle: [ Adult (32 Teeth) ] or [ Pediatric (20 Teeth) ].           │
│  • Click Tooth -> Select Surface (MODBL) -> Assign Condition:          │
│    [ Red: Caries ]  [ Blue: Existing Filling ]  [ Gray: Missing ]      │
│  • Add Procedure -> Mark "Completed" -> Click [ Sync to Billing ].     │
│                                                                        │
│  4. E-PRESCRIPTION (Rx)                                                │
│  • Type first 3 letters of drug name -> Select from catalog presets.   │
│  • Dosage, frequency, and instructions auto-fill.                      │
│  • SAFETY ALERT: If drug allergy conflict triggers, either pick an     │
│    alternative or enter mandatory clinical override justification.     │
│  • Click [ Finalize & Sign Rx ] -> Click [ Print PDF ].                │
│                                                                        │
│  5. COMPLETE ENCOUNTER                                                 │
│  • Click [ Complete Consultation ].                                    │
│  • Patient is automatically routed to reception for checkout.          │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```
